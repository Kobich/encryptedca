# План миграции и дальнейшей работы

Исходный план из начала работы: переписать Java + XML на Kotlin + Compose по шагам. Сроков по времени мы не ставили, план был только по порядку этапов.

## Исходный план

- [x] **1. Gradle.** Kotlin (встроенный в AGP 9), Compose BOM, Material3, lifecycle, корутины.
- [x] **2. Логика на Kotlin.** Чтение `.p12`/CA, хранилище, TLS. Формат хранения на устройстве сохранён: алиасы Keystore, `.ca.enc`, ключи SharedPreferences.
- [x] **3. ViewModel на `StateFlow` + корутины** вместо `LiveData` + `ExecutorService`.
- [x] **4. Экраны на Compose.** Фрагменты, XML-лейауты, appcompat и material-views удалены.
- [ ] ~~**5. Тесты на Kotlin.**~~ Отменено: тесты сознательно удалены, пока не пишем.

## Исправления из первичного разбора кода

- [x] Выбор профиля во время обновления списка больше не теряется: операции идут по очереди.
- [x] Длина пароля больше не пишется в лог.
- [x] Просроченный CA показывается как «сертификат не подходит», а не как ошибка хранилища.
- [x] Профили сортируются по дате добавления, а не по UUID.
- [x] Убрана бессмысленная проверка коллизии UUID.
- [x] Пустой пароль `.p12`: оставлен только вариант с одним NUL-символом.

## Сделано сверх плана

- [x] **Модули:** `:app`, `:core:certificates`, `:core:network`, `:feature:certificates`, `:feature:scanner`. Навигация на Navigation Compose.
- [x] **Исправления по ревью:**
  - хранилище разделено на ключ, CA и индекс;
  - всё, кроме репозитория и моделей, стало `internal`;
  - `:core:network` больше не знает про Keystore (`ClientCredentials`);
  - `DocumentReader` вынесен из ViewModel;
  - превью экранов, дата вместо UUID в карточке.
- [x] **TLS только в роли клиента:** ключ из `.p12` подтверждает нас, `ca.pem` проверяет сервер.
- [x] **Сканер устройств в текущем Wi-Fi:**
  - сеть без интернета тоже подходит;
  - сокеты привязаны к Wi-Fi;
  - проверка порта 443 и mTLS-handshake;
  - статусы «своё / не прошло проверку».
- [x] `.gitignore`, README, `sample-certificates/README.md`.
- Пробовали и откатили: convention-плагины в `buildSrc` и модуль `:core:ui`. Для такого размера это лишнее.
